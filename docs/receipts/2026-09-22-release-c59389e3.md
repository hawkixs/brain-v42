## Why this release exists

The three pull requests it carries were merged but **not deployed**, and the gap mattered more
than usual. The writers run from `releases/<sha>/`, so a merge to `main` is not live at the next
restart — and the embedding-provider switch restarts the MCP as part of its own sequence. Had
the switch run against the previous release, it would have restarted into code where the
runbook's `~` path raised at construction, where reindexing snippets redefined 195 rows, and
where re-indexing the 208 stale plans reopened every one of their feature assignments.
